## 四、下一步选题（按性价比）

### 选项 A：把「AI 优化大师」升级成「harness 性能优化」（推荐）
- 证据：`ECC` 用「harness performance optimization」拿到 298k star；我们已有 `dsh-cost`（成本）、`dsh-cache-stabilizer`、`dsh-squeeze` 相关资产、U-King 的 metrics 设计稿。
- 做法：从「文件清理」扩到「可测量的性能」——token 消耗、上下文占用、首 token 延迟、重复读取；给 before/after 对照。
- 风险：指标体系容易变成自嗨分数，必须每个数字可下钻到原始日志。

### 选项 B：中文优先的 skill 市场/管理器
- 证据：搜索联想里「市场/推荐」出现频率最高；`skills` npm 周下载 536 万。
- 做法：不是再造一个 Skiller（51★），而是做「中文 skill 索引 + 一键装到 DSH/Claude/Codex」。
- 风险：内容运营重，需要持续策展；先做索引可以用爬取+人工复核。

### 选项 C：单点强能力 skill（像 `rea` / `last30days`）
- 证据：`mvanhorn/last30days-skill` 66k star，就是一个「跨平台研究任何话题」的 skill。
- 做法：把某个我们真做过的能力做成一句话就能用的 skill（如「公司主体/资质核验」「报价单生成」）。
- 风险：需要真实数据源与可验证输出，否则是玩具。

**建议顺序：A → C → B。** A 能复用现有资产且有最大的对标成功案例；B 运营成本最高；C 依赖具体数据源。
