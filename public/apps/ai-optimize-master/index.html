AI 优化大师

AI 工具装得越多，技能目录越乱：同一份 skill 被复制到四五个工具、引用指向早已不存在的脚本、升级后没人知道哪份是原件。先查清，再动手。

看源码npm 安装

免费 · 开源 · 不联网 · 不需要账号

它解决什么

同名重复同一份 skill 在多个工具里各有一份；区分「内容完全一致」与「已经分叉」。
断链引用SKILL.md 让 AI 去读某个脚本，但文件已经不存在——列出具体缺失路径与行号。
过期配置Windows 绝对路径、过时端口、只在旧系统成立的写法，逐条列出。

怎么工作

npx ai-optimize-master scan     # 只读体检，不改任何东西
npx ai-optimize-master evolve   # 输出改进提案与 diff，不自动修改
npx ai-optimize-master plan --select <skill> --out plan.json
npx ai-optimize-master apply --plan plan.json --expect <planHash>

执行必须出示方案哈希：没有哈希会被拒绝，方案被改过也会被拒绝。每一步写入 journal，undo 可还原；如果你在之后又编辑过文件，它报冲突而不是覆盖。

本机实测

  • 探测到 11 个正在使用的 AI 工具技能根，约 400 个 skill
  • 38 组同名重复，其中 29 组内容完全一致
  • 71 个 skill 引用了不存在的本地文件
  • MCP 声明：Claude 1 处、Codex 5 处、Cursor 1 处（只读统计，不改配置）

数字来自一次真实扫描；它会随机器变化，不构成承诺。

安全边界

  • 默认只读；执行只做「归档」，不永久删除
  • 只处理落在已声明技能根目录内的目录，越界拒绝
  • 拒绝符号链接，避免顺着链接跑到根目录外
  • 只读 MCP 只暴露 scan / plan，远程调用方无法改你的机器
  • 不用 AI 改写你的 SKILL.md；不做全自动清理

常见问题

它会删我的文件吗？不会。执行时只把选中的目录移动到归档目录，并写入 journal，可用 undo 逐字节还原。

它会自动改写我的 SKILL.md 吗？不会。evolve 只输出带证据与行号的提案和 diff，不自动修改任何技能正文。

能帮我清理 MCP 配置吗？当前版本只读统计 MCP 声明数量与条目，不修改配置，也不启动任何 MCP 服务。

支持哪些系统？macOS、Windows、Linux。默认探测 22 个已知 agent 技能根目录，目录不存在会跳过。

和 U-King 的「AI 优化大师」什么关系？同一个方向的两个入口：U-King 管环境体检与一键优化，这个工具管多工具的技能资产清单。
