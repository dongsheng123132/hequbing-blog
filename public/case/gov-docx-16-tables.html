问题

公文不能「读出来再重新生成」——那样页眉页脚、字体、自动编号全丢。必须原地改。

做法

  • 跨 run 定位：一个词常被拆在多个 run 里，要先拼接全文定位，再由首个非空 run 承载替换
  • 表格单独处理：16 张表逐表校验行列与合并单元格
  • 改完自动核对：编号连续性、交叉引用、页眉页脚一致性

结果

16 张表零丢失，版式与编号保持原样。

可复用

同一套方法后来做成了开源工具「长文档一致性检查」，离线跑，附精确位置。
