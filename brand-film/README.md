## 一键渲染

```bash
# 系统依赖（Ubuntu/Debian）
sudo apt install ffmpeg fonts-noto-cjk fonts-noto-cjk-extra libegl1
pip install -r requirements.txt

./make.sh              # 配乐 → 900 帧 → MP4 / 海报 / 联系表 → 自检
FORCE=1 ./make.sh      # 强制重渲所有帧
```

4 核 CPU 约 10 分钟（渲染约 5 分钟、编码 2 分钟、自检 3 分钟）。单独预览某些时刻：`cd src && python3 preview.py 0 3.125 10.7`，结果在 `build/preview/`。

## 结构

```
src/timeline.py    96 BPM · 4/4 · 6 小节 · 60 fps；全片的时间唯一来源（音画共用）
src/audio.py       原创配乐：纯程序合成（FM 钟、毡音钢琴、失谐锯齿弦乐组、木石敲击、卷积混响）
src/scene.py       整片是一个连续的三维世界：石墨暗厅 → 端墙窄缝 → 象牙白业务厅 → 品牌落版
src/engine3d.py    小型确定性矢量 3D 渲染器（Skia）：近裁剪、画家排序、AO、软阴影、透视贴字
src/typography.py  中文排版：字距、标点挤压、去尾标点的视觉居中
src/render.py      逐帧渲染（半浮点画布，大面积渐变无色阶）+ 选择性运动模糊（时间超采样）+ 纸纤维 / 暗角 / 抖动颗粒
src/finish.py      编码封装、海报、联系表
src/qa.py          自检：规格、时长、音画同步、缺字、闪帧、落版稳定、手机预览
```

## 常见修改

- **文案**：`scene.py` 的 `txt()`。改完字后若子集字体缺字，会自动改用系统完整字体；两者都缺字时停止渲染，不会出豆腐块。
- **品牌字标 / 朱红记号**：`draw_brand()` 与 `STROKE_HALF`、`STROKE_W`，字标和记号是分开的两层，后续可以换成正式 Logo。
- **节拍与动作**：只改 `timeline.py`，音乐和画面会一起移动。
- **配色**：`engine3d.py` 顶部三色 `GRAPHITE / IVORY / VERMILION`，其余色调都由这三色混合得到。
